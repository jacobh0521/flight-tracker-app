About This Project

This application is a real-time flight tracking dashboard designed to visualize air traffic data. It allows users to monitor flight departures, view live aircraft positions on an interactive map, and analyze delay metrics for specific airports using data from the OpenSky Network.

Tech Stack & Tools

  • Python & Flask: Backend server logic, API routing, many python libraries.
  • OpenSky Network API: Source for live flight state vectors and departure data.
  • HTML & Tailwind CSS: Responsive frontend structure and styling.
  • JavaScript (Chart.js & Leaflet): Interactive data visualization and mapping.
  • Docker: Containerization for consistent development and deployment.
  • Google Cloud Run: Serverless platform for hosting the application.
  • Powerbi: Data visualization and reporting tool. Used for the departure metrics dashboard.
